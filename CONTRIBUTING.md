# Contributing to ABC.01

ABC.01 is governed by one canonical Core. Product editions must not fork safety, evidence, service ontology, preview semantics, or professional authority.

## Required change discipline
1. Identify the owning Core contract/engine.
2. Preserve evidence classes and Safety precedence.
3. Add/adjust tests before claiming PASS.
4. Record build/evidence hashes.
5. Update Notion governance mirror after meaningful state changes.
6. Human approval is required for canonical locks, authority changes, ontology expansion, safety-boundary changes, pilot/production claims, and irreversible release actions.

## Never commit
`.env.local`, API secrets, client images, session data, credentials.
