## Important product rule

Trend status never overrides source reality, Safety, feasibility, client exclusion, maintenance tolerance, salon capability or Specialist Validation.

A trend-current beard style is **not eligible** if the visible beard coverage does not support it. ABC must prefer fewer valid options over filling slots with an impossible look.
