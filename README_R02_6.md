# ABC.01 — R02.6 Recommendation Runtime

Status: engineering implementation candidate; not Pilot Ready or Production Ready.

## Governing sequence

Specialist-reviewed analysis → source-reality filtering → structural de-duplication → 1–3 valid Core directions → optional explicit Explore → canonical state publication → client selection → separate Specialist Validation.

## Hard contracts

- No ranked recommendation before specialist-reviewed analysis.
- Invalid source-reality candidates are filtered before ranking.
- Core contains 1–3 valid directions; three is a maximum, never a quota.
- Ordered roles are BEST_FIT, then ALTERNATIVE, then BOLDER, without gaps.
- Structurally duplicate directions never fill another role.
- Explore is 0–3 and explicit-only.
- Fixed Choice never auto-expands into Explore.
- Custom/composite direction components, service ownership, rationale, maintenance, tradeoff, constraints and preview readiness survive canonical compilation.
- Client Selection is not Specialist Validation.
- Commercial eligibility cannot reorder Core recommendations.

## Non-claims

Live recommendation quality validation, runtime product PASS, Pilot Ready and Production Ready remain false until their own evidence gates close.
